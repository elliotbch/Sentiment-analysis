Comment ça marche

  1. Modèle de départ : cardiffnlp/twitter-roberta-base-sentiment-latest, un RoBERTa pré-entraîné sur environ 124 millions de tweets.
  2. Fine-tuné sur le jeu public Tweet Sentiment Extraction (environ 27 000 tweets en anglais, 3 classes).
  3. La validation sert à choisir l’epoch et le modèle ; le test officiel (3 534 tweets) n’est utilisé qu’une fois, pour les chiffres ci-dessous.
  4. Exporté en ONNX et exécuté avec ONNX Runtime sur CPU ; le temps d’inférence affiché exclut la latence réseau.
  5. Limite connue : l’ironie et le sarcasme sont souvent lus au premier degré (essayez l’exemple « Sarcasme »).
